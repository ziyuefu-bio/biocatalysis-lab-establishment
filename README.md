# Biocatalysis Lab Establishment

## Overview

This repository documents the establishment of an industrial biocatalysis laboratory focused on nitrilase engineering, enzyme screening, and asymmetric biocatalysis workflows.

## Current Focus

- Nitrilase engineering
- Enzyme assay workflow
- Protein expression pipeline
- GC/HPLC analytical workflow
- Laboratory SOP development
- Experimental infrastructure design
